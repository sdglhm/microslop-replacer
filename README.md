# 📦 Microslop Replacer

A Chrome extension that automatically replaces all occurrences of **“Microsoft”** with **“Microslop”** on web pages.

This project was created as a direct response to public discourse around the term *“AI slop”* — including commentary on how the word *slop* was used in discussions of AI-generated content and corporate responses to that perception (e.g., calling out how technology leaders react to criticism of *slop* in AI outputs).([Futurism][1])


## 🧠 Why this exists

In late 2025 and early 2026, “slop” was selected by Merriam-Webster as the **Word of the Year** for 2025 due to its connection with pervasive low-quality, AI-generated digital content (e.g., generative text, art, and media). In response, *Microsoft’s CEO publicly encouraged people to stop using “slop” to criticize the company’s output, advocating instead for focusing on distinguishing hype from substance*.([Futurism][1])

This extension playfully applies that sentiment by transforming every instance of the name *Microsoft* in web content to *Microslop*.

⚠️ **Note:** This tool is intended as a personal/experimental project and not affiliated with Microsoft or any official product.


## 🧩 Features

* Replaces all visible occurrences of **Microsoft** with **Microslop**
* Works on dynamically loaded pages (e.g., SPAs)
* Case-sensitive replacement (upper and lower forms handled)
* Does **not** touch input fields, code blocks, or editable content

## 🛠 Installation

1. Clone or download this repository.
2. Open **Chrome** and go to `chrome://extensions`.
3. Enable **Developer mode** in the top right.
4. Click **Load unpacked** and select this project folder.
5. Pin the extension to your toolbar if desired.


## 🧪 Example

After installation, any page containing “Microsoft” will display **Microslop** instead — including article text, menus, and other on-page content.
